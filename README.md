## 📝 Description
This plugin adds placeable Guillotines to Counter-Strike 1.6, allowing players to execute themselves or other players with a classic guillotine.
- Place and configure Guillotines around the map
- Execute players with a dramatic blade-drop animation
- Randomize detached head models and launch them in the Guillotine direction
- Customize blade speed, hold duration and usage cooldown
- Configure affected teams and usage restrictions by team
- Customize head launch velocity, rotation and lifetime
- Play configurable impact and slicing sounds
- Display customizable execution messages and HUD effects
- Save and load Guillotine placements per map
- Configure default behavior and create custom Guillotine presets

## ⚙️ Configuration
```ini
# To add a new Guillotine, follow the example below:
# [Guillotine Name]
# GUILLOTINE_TEAM       = 0 - None, 1 - Terrorist, 2 - Counter-Terrorist, 3 - Both
# GUILLOTINE_COOLDOWN   = Minimum and maximum cooldown duration (MIN MAX)
#
# Define a section name to make a Guillotine available in the menu.
# Models and sounds cannot be changed dynamically during gameplay.
```
